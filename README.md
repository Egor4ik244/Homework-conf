# Транслятор конфигурационного языка — вариант 13

Утилита читает конфигурацию из стандартного ввода, разбирает её с помощью
Lark, вычисляет константные выражения и записывает результат в YAML
с помощью PyYAML.

## Установка

Из корня репозитория выполни команды в macOS или Linux. Проект проверен
на Python 3.13. Для запуска достаточно установить зависимости.

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
```

## Запуск

```sh
./run.sh -o /tmp/server.yaml < examples/server.conf
```

Параметр `-o` задаёт путь к выходному файлу и обязателен при преобразовании.
Ключ `-h` выводит справку. Код завершения `0` означает успех, `1` — ошибку
разбора, вычисления или ввода-вывода, `2` — ошибку в аргументах командной
строки. Сообщения об ошибках выводятся в стандартный поток ошибок.

## Синтаксис

| Конструкция | Правило |
| --- | --- |
| Комментарий | Начинается с `#` и продолжается до конца строки. |
| Имя | Одна или несколько строчных латинских букв, например `timeout`. |
| Число | Экспоненциальная запись, например `2e1` или `-2.5E-1`. |
| Строка | Текст внутри `q(...)`, например `q(Северная)`. |
| Словарь | Записи вида `имя: значение;` внутри фигурных скобок. Словари могут быть пустыми и вложенными. |
| Константа | Объявление вида `(def base 2e1);` перед корневым словарём. |
| Выражение | Запись вида `@[base 1 +]`. Внутри допустимы целые числа и ссылки на ранее объявленные константы. |

Во входном тексте после объявлений констант идёт один корневой словарь.
В постфиксном выражении операция стоит после двух операндов.
`@[2 3 +]` даёт `5`, `@[5 2 -]` даёт `3`, а `@[2 3 pow()]` даёт `8`.
Результат выражения используется как значение. Выражение `@[base]`
подставляет значение константы целиком.

## Примеры

### Настройки веб-сервера

Входной файл — [examples/server.conf](examples/server.conf).

```sh
./run.sh -o /tmp/server.yaml < examples/server.conf
cat /tmp/server.yaml
```

```yaml
server:
  host: localhost
  timeout: 21.0
```

### Настройки теплицы

Входной файл — [examples/greenhouse.conf](examples/greenhouse.conf).

```sh
./run.sh -o /tmp/greenhouse.yaml < examples/greenhouse.conf
cat /tmp/greenhouse.yaml
```

```yaml
greenhouse:
  name: Северная
  temperature: 22.0
```

## Тесты

```sh
python -m unittest discover -s tests -v
```

Тесты проверяют вложенные словари, комментарии, числа, строки, объявления
и ссылки на константы, арифметические операции и обработку ошибочного ввода.

## Основные файлы

- `src/grammar.lark` описывает грамматику конфигурационного языка.
- `parse_config(text)` в `src/parser.py` возвращает дерево разбора Lark.
- `config_to_dict(text)` вычисляет выражения и возвращает словарь Python.
- `main()` в `src/main.py` обрабатывает параметры, читает ввод и пишет YAML.
- `run.sh` запускает командную утилиту.
